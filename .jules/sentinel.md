
## 2025-02-14 - Fix XSS Vulnerability in GlobalSearch component
**Vulnerability:** The GlobalSearch component in `admin-panel/client/src/components/ui/GlobalSearch.tsx` directly rendered search results (`result.highlighted.title` and `result.highlighted.description`) into the DOM using `dangerouslySetInnerHTML` without proper sanitization. This introduced a significant Cross-Site Scripting (XSS) vulnerability if the search backend returned malicious HTML content, enabling attackers to execute arbitrary JavaScript in the context of the admin panel.
**Learning:** Even when data originates from an internal or seemingly trusted source (like an internal search API), directly injecting raw HTML using `dangerouslySetInnerHTML` is extremely dangerous. The frontend must always be defensively programmed and cannot inherently trust the backend output, especially for complex features like search highlights where HTML formatting is explicitly desired and passed back to the client.
**Prevention:** Always sanitize any dynamic HTML content before rendering it with `dangerouslySetInnerHTML`. We used `DOMPurify.sanitize()` from the `dompurify` library to safely strip out any malicious scripts or attributes while preserving the necessary benign HTML tags (like `<em>` or `<b>` for highlighting). Never use `dangerouslySetInnerHTML` on unsanitized input.
