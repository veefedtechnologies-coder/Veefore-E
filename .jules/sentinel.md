## 2024-05-24 - Cross-Site Scripting (XSS) in Global Search Results\n**Vulnerability:** Found `dangerouslySetInnerHTML` being used to render search result highlights without sanitization in `GlobalSearch.tsx`.\n**Learning:** The `dangerouslySetInnerHTML` API in React bypasses its built-in XSS protections. Passing unsanitized data directly to this API creates a critical XSS vector.\n**Prevention:** Always sanitize any dynamic or user-generated HTML content using a library like DOMPurify before passing it to `dangerouslySetInnerHTML`.
