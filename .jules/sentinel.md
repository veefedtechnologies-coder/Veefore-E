## 2024-05-24 - [CRITICAL] Remove Hardcoded Secrets
**Vulnerability:** A hardcoded fallback secret (`"fallback-secret-for-development"`) was used for Express session management when `SESSION_SECRET` was absent, exposing sessions to hijacking if the environment variable was accidentally omitted in production. Similarly, a hardcoded fallback (`"development-only-secret-key"`) was provided in `server/config/env.ts` for `JWT_SECRET`.
**Learning:** Using hardcoded fallback values for cryptographic secrets or session keys in code completely undermines the purpose of environment variables. If an environment variable is required for security, the application should fail securely (crash or refuse to start) rather than silently falling back to a known insecure value.
**Prevention:** Remove fallback string values for critical secrets (`JWT_SECRET`, `SESSION_SECRET`). Enforce their presence via environment validation logic (like Zod) and throw a definitive error if they are missing when needed.
