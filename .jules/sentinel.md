## 2026-09-10 - Math.random() considered harmful for cryptographic use cases
**Vulnerability:** Weak random numbers in password and OTP generation. `Math.random()` was being used to generate one-time passwords and shuffle password characters in `admin-panel/server/utils/credentialGenerator.ts` and `admin-panel/server/utils/security.ts`. `Math.random()` provides unpredictable outputs suitable for non-security use cases but is not cryptographically secure and can be theoretically reverse-engineered.
**Learning:** Security-sensitive functions, such as those generating passwords or authentication tokens, must leverage `crypto.randomInt` or `crypto.randomBytes` in Node.js instead of native `Math.random()`. Fisher-Yates is a good algorithm to shuffle a string array, but it should also use `crypto.randomInt()`.
**Prevention:** Always use Node.js's native `crypto` module (`crypto.randomInt()`, `crypto.randomBytes()`) for generating any sensitive tokens or random strings. Additionally, replace `.sort(() => Math.random() - 0.5)` with a proper Fisher-Yates shuffle utilizing `crypto.randomInt()`.
