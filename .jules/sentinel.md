## 2024-05-18 - Stack Trace Leakage in Error Responses\n**Vulnerability:** Information Exposure via Stack Trace (CWE-209). Stack traces and detailed error messages were returned to clients in 401 Unauthorized responses within video authentication routes.\n**Learning:** Global error handlers might not catch all exceptions if custom try/catch blocks return HTTP responses directly without sanitization. In Express applications, returning `error.stack` and raw `error.message` directly into `res.json()` can expose sensitive internal server architecture and implementation details.\n**Prevention:** Ensure that all HTTP responses generated inside catch blocks fail securely by returning generic error messages (e.g., "Unauthorized" or "Internal Server Error") and omitting stack traces, especially in production environments.
