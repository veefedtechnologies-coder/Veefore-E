## 2024-05-18 - Fix Error Handling Leaking Sensitive Details\n**Vulnerability:** HTTP 500 error responses were returning the `error.message` and sometimes `error.stack` inside a `details` object.\n**Learning:** This is a common pattern for leaking internal server information to the client, which violates the security principle of "fail securely".\n**Prevention:** Never include internal error strings or stack traces in HTTP responses; keep `details` empty or use generic messages, and retain full errors in server logs using `console.error`.
