# Video Generator Feature Module

This module contains the extracted components from `VideoGeneratorAdvanced.tsx` (originally 3,125 lines) as part of the codebase refactoring initiative.

## Overview

The video generator feature enables users to create AI-powered videos through a multi-step wizard interface. This refactoring extracts the first step (prompt input) into a focused, reusable component.

## Components

### VideoPromptStep

The first step in the video generation wizard. Provides a clean, Gemini-inspired interface for users to enter their video idea.

**Features:**
- Centered greeting and subtitle
- Suggestion cards with example prompts
- Auto-expanding textarea with max height
- Tool buttons (attachments, settings, voice input)
- Generate button that appears when prompt is entered
- Loading state during script generation

**Props:**
```typescript
interface VideoPromptStepProps {
  prompt: string;
  setPrompt: (prompt: string) => void;
  onGenerateClick: () => void;
  isGenerating: boolean;
  onToolsModalOpen: () => void;
}
```

**Usage Example:**
```tsx
import { VideoPromptStep, useVideoGeneration } from '@/features/video-generator';

function VideoGenerator() {
  const { 
    prompt, 
    setPrompt, 
    generateScript, 
    isGenerating 
  } = useVideoGeneration();

  return (
    <VideoPromptStep
      prompt={prompt}
      setPrompt={setPrompt}
      onGenerateClick={generateScript}
      isGenerating={isGenerating}
      onToolsModalOpen={() => setShowToolsModal(true)}
    />
  );
}
```

1. Importing the component and hook:

