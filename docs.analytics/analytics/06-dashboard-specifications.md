Chapter 13 — Dashboard Navigation Rules
Every KPI opens its dedicated analytics page.
Every chart supports drill-down.
Every table row opens the related content or campaign.
Every AI insight links to evidence.
Every dashboard remembers user preferences (layout, filters, columns).
Chapter 14 — Mobile & Tablet Adaptation
Desktop remains the primary experience.
Tablet:
Two-column layout where possible.
Full functionality with touch-friendly controls.
Mobile:
KPI cards become swipeable.
Charts stack vertically.
Tables become simplified lists with expandable rows.
Heavy analysis pages prioritize summaries over dense visualizations.
